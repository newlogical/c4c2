Apartment Controller — Full Setup & Commissioning Guide

Self‑hosted Control4‑style controller  •  Windows 11 mini‑PC  •  Host IP 192.168.0.10  •  Viewed from an iPad on the same Wi‑Fi
How this works in one sentence: the app runs on your always‑on mini‑PC on the apartment network; your iPad opens it like an app; each real device (matrix, amp, TVs, thermostat, cameras) is switched from demo to LIVE once you enter its address.

Part 0 — What you're building & your equipment

You are installing a touchscreen "smart apartment" controller — like Control4 — that runs on your own mini‑PC. It gives you one screen to watch video, play audio by room, control the thermostat, view cameras, and run "scenes" (one tap = many actions).

Your rack equipment this controls

WS66i 6‑zone amplifierAudio per room: Living, Office, Master, Bathroom — volume, mute, sourceEthernet (LAN IP)

4 × Sony Bravia KD‑49X7000E (Living, Office, Master, Guest)Power on/off, volume, HDMI input, remote keysLAN IP + Pre‑Shared Key + Wake‑on‑LAN (MAC)

Until you enter a device's real address and flip it to LIVE, that device runs in demo/simulation — perfectly safe to explore the app first.

You'll need these to hand before you start

  • The mini‑PC connected by Ethernet cable to your network (not Wi‑Fi if possible).
  • Admin access to your UniFi router (to reserve the IP and later enable camera RTSP).
  • The iPad on the same Wi‑Fi.
  • About 45–60 minutes for the software setup, plus time per device.

Part 1 — Prepare the mini‑PC

1.1 Give it a permanent IP address

The app is reached at a fixed address, so the mini‑PC must always keep the same IP.

  • Log in to your UniFi controller (e.g. https://unifi.ui.com or the Dream Machine's local page).
  • Go to Client Devices, find the mini‑PC, open it, choose Settings → Fixed IP and set it to 192.168.0.10.
  • Make sure the mini‑PC is on the same network/VLAN as the matrix, amp, TVs, Ecobee and cameras.

1.2 Stop it from sleeping

Windows → Settings → System → Power & battery → Screen and sleep. Set every "Sleep" and "Screen off" option to Never. A controller must stay awake.

Why not Docker on Windows? Docker Desktop on Windows isolates the network and breaks Wake‑on‑LAN (needed to power your TVs) and device discovery. So we run the app natively on Windows. (If you ever reinstall the PC with Ubuntu Linux, you can instead use the one‑command docker compose up method in SELF_HOST.md.)

Part 2 — Install the prerequisite software

Download and install each of these on the mini‑PC. Where an installer offers "Add to PATH", tick it.

2.1 Enable Yarn

Open PowerShell (Start menu → type "PowerShell") and run:

corepack enable
corepack prepare yarn@stable --activate

2.2 Verify everything is installed

Close PowerShell, open a new one, and run:

git --version
python --version
node --version
yarn --version
ffmpeg -version

Each should print a version number. If one says "not recognized", re‑run that installer and be sure "Add to PATH" is ticked, then open a fresh PowerShell.

2.3 Add ffmpeg to PATH (if the installer didn't)

Start menu → type "environment variables" → Edit the system environment variables → Environment Variables → under "System variables" select Path → Edit → New → paste C:\ffmpeg\bin → OK. Reopen PowerShell and re‑test ffmpeg -version.

Part 3 — Get the app code onto the PC

Recommended: via GitHub (lets you receive updates later)

  1. In the Emergent chat, click "Save to GitHub" and follow the prompts to push this project to your GitHub account. Copy the resulting repository URL.
  2. On the mini‑PC, in PowerShell (replace with your real URL):
cd C:\
git clone https://github.com/<your-username>/<your-repo>.git apartment-controller
cd apartment-controller

To pull future updates later: cd C:\apartment-controller then git pull.

Alternative: ZIP download

Download the project as a ZIP, then extract it to C:\apartment-controller.

From here we assume the project lives at C:\apartment-controller and contains a backend folder and a frontend folder.

Part 4 — Start the backend (the API)

In PowerShell:

cd C:\apartment-controller\backend

# create an isolated Python environment
python -m venv .venv
.\.venv\Scripts\Activate.ps1

# install dependencies
pip install -r requirements.txt

# optional: Apple TV control support
pip install pyatv

4.1 Create the backend config file

Create a file named exactly .env inside C:\apartment-controller\backend. Open Notepad, paste the block below, then File → Save As, set "Save as type: All Files", and name it .env (not .env.txt).

MONGO_URL=mongodb://localhost:27017
DB_NAME=c4clone
CORS_ORIGINS=*
DEFAULT_PIN=1234

4.2 Run the backend

.\.venv\Scripts\Activate.ps1
uvicorn server:app --host 0.0.0.0 --port 8001

Leave this window open. Test it: on the mini‑PC open a browser to http://localhost:8001/api/ — you should get a response (not an error page).

Part 5 — Build & start the frontend (the UI)

Open a second PowerShell window (leave the backend running in the first):

cd C:\apartment-controller\frontend
yarn install

5.1 Create the frontend config file

Create a file named .env inside C:\apartment-controller\frontend with this one line. This bakes in the mini‑PC's IP so the iPad knows where the API is:

REACT_APP_BACKEND_URL=http://192.168.0.10:8001

5.2 Build and serve the UI

yarn build
npx serve -s build -l 3000

Leave this window open too. Test on the mini‑PC: http://localhost:3000.

Remember: any time you change frontend\.env (e.g. a new IP), you must run yarn build again — the address is baked in at build time.

Part 6 — Open the Windows firewall

So the iPad can reach the mini‑PC. Right‑click Start → Terminal (Admin) / PowerShell (Admin), then:

New-NetFirewallRule -DisplayName "Apartment UI 3000"  -Direction Inbound -Protocol TCP -LocalPort 3000 -Action Allow
New-NetFirewallRule -DisplayName "Apartment API 8001" -Direction Inbound -Protocol TCP -LocalPort 8001 -Action Allow

Part 7 — Open it on the iPad

  1. Make sure the iPad is on the same Wi‑Fi as the mini‑PC.
  2. Open Safari and go to: http://192.168.0.10:3000
  3. Enter the PIN — default 1234 (you'll change this in Part 11).

7.1 Make it a full‑screen app

  • In Safari tap the Share icon → Add to Home Screen. Launch it from the new icon — it opens full‑screen, no browser bars.
  • If it's a wall‑mounted iPad: Settings → Display & Brightness → Auto‑Lock → Never, and turn on Guided Access (Settings → Accessibility) to lock it to this one app.

Part 8 — Switch each device to LIVE

Everything is in demo until you do this. In the app tap Settings (gear, top‑right) → On‑site commissioning guide. For each device: toggle LIVE, fill the fields, tap Test connection, then Save.

8.1 JTECH‑MXT40 matrix (video routing)

  • In the matrix's own web page, enable Telnet (TCP port 23).
  • App → JTECH‑MXT40 Matrix → enter its IP and port 23.

8.2 WS66i amplifier (room audio)

  • On the amp's rear network switch select ETHERNET; give it a fixed IP (reserve it in UniFi).
  • App → WS66i Amplifier → enter its IP.
  • Source → input map: for each logical source (Apple TV 1‑4, Spotify, AirPlay, TV Audio) enter the physical WS66i input number (1‑6) it is actually wired to. This is what makes the correct source play in each zone.

8.3 Apple TVs (video sources + remote)

On the mini‑PC, with the backend venv active:

cd C:\apartment-controller\backend
.\.venv\Scripts\Activate.ps1
atvremote scan

Then pair each unit (repeat for all four, using each device's id from the scan):

atvremote --id <device-id> pair

Enter the PIN shown on that Apple TV screen, and save the credentials it prints. Then App → Apple TVs → enable LIVE.

8.4 Sony Bravia TVs — Living, Office, Master, Guest

TVIPMAC
Living Room TV192.168.0.1651C:D6:BE:B3:FB:1C
Office TV192.168.0.177FA:8A:FD:3F:67:FC
Master Bedroom TV192.168.0.78FA:D8:24:B4:79:2F
Guest Room TV192.168.0.2538E:BF:A2:FC:72:BF

On each TV first: Settings → Network → Home network setup → IP control:

  • Authentication = Normal and Pre‑Shared Key, then set a Pre‑Shared Key (e.g. a 4‑digit code).
  • Remote start = ON (wake from the network).
  • Turn off private / random Wi‑Fi MAC so Wake‑on‑LAN and the UniFi IP reservation keep matching.

App → Sony Bravia TVs → for each TV confirm IP + MAC, then enter the PSK and the HDMI port its HDBaseT receiver feeds. Power‑on sends Wake‑on‑LAN; everything else uses the Bravia REST/IRCC API.

Waking a Sony over Wi‑Fi is often unreliable. A wired Ethernet connection to each TV gives the most dependable power‑on.

8.5 Ecobee thermostat

  • Ecobee no longer issues developer API keys, so the app pairs locally over HomeKit.
  • Keep the thermostat out of Apple Home (it can only pair with one HomeKit controller at a time).
  • App → Settings → Ecobee Thermostat → LIVE → confirm IP 192.168.0.222 → enter the 8-digit code from the thermostat (Menu → Settings → HomeKit) → Pair thermostat.
  • Windows: allow Python on Private networks so mDNS discovery (UDP 5353) works.

8.6 UniFi cameras

  • In UniFi Protect, open each camera → enable RTSP and copy the stream URL (looks like rtsp://<NVR-IP>:7447/<streamID>_0).
  • App → UniFi Protect Camera (or the setup wizard) → paste each camera's RTSP URL.
  • The backend converts RTSP to a browser‑friendly stream using ffmpeg (installed in Part 2).

Part 9 — Auto‑start on boot

So the controller comes back by itself after a power cut. Create two small batch files.

C:\apartment-controller\start-backend.bat

cd /d C:\apartment-controller\backend
call .venv\Scripts\activate.bat
uvicorn server:app --host 0.0.0.0 --port 8001

C:\apartment-controller\start-frontend.bat

cd /d C:\apartment-controller\frontend
npx serve -s build -l 3000

Then open Task Scheduler → Create Task (do this once per .bat):

  • General: tick "Run whether user is logged on or not".
  • Triggers: New → Begin the task At startup.
  • Actions: New → Start a program → browse to the .bat file.

Both services now launch automatically at boot. (For a cleaner install you can run each as a Windows service using NSSM — nssm.cc.)

Part 10 — Remote access (using it away from home)

Never forward ports 3000/8001 to the internet. Use a private VPN instead.

Option A — Tailscale (easiest, free)

  1. Install Tailscale on the mini‑PC (tailscale.com/download) and sign in.
  2. Install the Tailscale app on the iPad and sign in with the same account.
  3. Find the mini‑PC's tailnet IP (starts with 100.).
  4. Rebuild the frontend with that IP: edit frontend\.env → REACT_APP_BACKEND_URL=http://100.x.y.z:8001, then yarn build. Open http://100.x.y.z:3000 from anywhere.

Option B — UniFi WireGuard / Teleport

UniFi Network → VPN → WireGuard / Teleport → create a client, load it on the iPad. Once the VPN is connected, just browse to the normal LAN address http://192.168.0.10:3000.

Part 11 — Security & the PIN

  • Change the default PIN from 1234 in the app: Settings → Change PIN.
  • Keep the controller on your LAN only; use the VPN in Part 10 for remote access.
  • Treat Sony PSKs and HomeKit pairing data as secrets — don't share them.

Part 13 — Final checklist

  • Mini‑PC has fixed IP 192.168.0.10 and never sleeps
  • Git, Python 3.11, Node 20, MongoDB (service), ffmpeg installed & on PATH; Yarn enabled
  • Code cloned to C:\apartment-controller
  • backend\.env created; backend running on port 8001; /api/ responds
  • frontend\.env points to http://192.168.0.10:8001; yarn build done; UI serving on port 3000
  • Firewall rules added for ports 3000 and 8001
  • iPad opens http://192.168.0.10:3000 and added to Home Screen
  • Each device entered & switched to LIVE; "Test connection" passes
  • WS66i source → input map matches the actual wiring
  • Sony TVs: IP control PSK set + Remote start ON; PSK + HDMI port entered in the app
  • Device health panel shows every device online
  • Auto‑start tasks created for backend & frontend
  • Default PIN changed from 1234
  • (Optional) Tailscale/VPN set up for remote access
